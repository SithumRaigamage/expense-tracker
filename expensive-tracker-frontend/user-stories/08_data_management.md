# User Story: Data Management & Export

## Current Status
- No explicit data export/import functionality visible in the frontend logic.
- Localized settings for currency and theme.

## Proposed Improvements for Individual Use

### 1. CSV/Excel Data Export
- **Story**: As a user, I want to export my transaction history to CSV so I can perform my own complex analysis in Excel or keep a local backup.
- **Benefit**: Data ownership and flexibility.

### 2. Bulk Transaction Import
- **Story**: As a user, I want to import transactions from my bank's CSV statement so I don't have to enter them manually.
- **Benefit**: Huge time saver for manual tracking.


### 4. Tax Report Generator
- **Story**: As a user, I want to generate a summary of tax-deductible expenses (if categorized correctly) for a specific financial year.
- **Benefit**: Simplifies annual tax filing.
