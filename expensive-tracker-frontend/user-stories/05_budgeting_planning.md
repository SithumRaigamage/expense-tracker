# User Story: Budgeting & Financial Planning

## Current Status
- Users can create a monthly budget.
- Basic budget vs actual tracking.

## Proposed Improvements for Individual Use

### 1. Rollover Budgets
- **Story**: As a user, I want unspent budget from one month to "roll over" to the next month for specific categories (e.g., "Travel Fund").
- **Benefit**: Rewards saving in one month by allowing more flexibility in the next.

### 2. Budget Alert System
- **Story**: As a user, I want to receive notifications when I have reached 80%, 90%, and 100% of my budget for a category.
- **Benefit**: Real-time spending control before it's too late.

### 3. "Envelope" Goal System
- **Story**: As a user, I want to virtually set aside money for specific needs (e.g., "Car Repair") that is separate from my general spending budget.
- **Benefit**: Discipline-based budgeting similar to the physical envelope method.

### 4. Zero-Based Budgeting Mode
- **Story**: As a user, I want to assign "every dollar a job" until my remaining income for the month is zero.
- **Benefit**: Maximum efficiency in wealth building.
