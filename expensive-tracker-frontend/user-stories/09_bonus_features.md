# User Story: Advanced Features (Bonus)

## Proposed Improvements for Individual Use

### 1. Debt Management Tracker
- **Story**: As a user, I want a dedicated module to track loans (Personal, Mortgage, Student) and use "Snowball" or "Avalanche" methods for repayment planning.
- **Benefit**: Strategy-based debt reduction.

### 2. Financial Health Score
- **Story**: As a user, I want a "Health Score" based on metrics like Savings Rate, Emergency Fund status, and Debt-to-Income ratio.
- **Benefit**: Holistic view of financial wellness beyond just a balance.

### 3. Shared Household Wallets (Optional)
- **Story**: As a user, I want to share a specific wallet (e.g., "Groceries") with my spouse while keeping my personal wallets private.
- **Benefit**: Collaborative budgeting for couples/families.

### 4. Multi-Platform Support (PWA)
- **Story**: As a user, I want to install this app on my phone as a PWA (Progressive Web App) so it feels like a native app.
- **Benefit**: Better accessibility and offline support.
